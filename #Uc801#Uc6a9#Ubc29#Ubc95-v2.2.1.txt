RecruitSystem-Pro v2.2.1 수정 패치

반영 내용
1. PDF 사진 삽입 오류 수정
2. 국적 선택 항목 추가
3. 병역사항 선택 항목 추가(군필/미필/면제/해당없음)
4. 전자서명 가이드 추가 및 가이드 영역만 저장
5. PDF를 A4 1페이지에 맞도록 높이/여백 축소
6. 희망고용방식은 PDF에서 제외하고 스프레드시트에는 유지
7. 국적/병역사항은 기존 열을 밀지 않고 스프레드시트 마지막 열에 추가

GitHub 프로젝트에서 교체할 파일
- index.html
- css/style.css
- js/script.js

주의
- js/config.js는 교체하지 마세요. 기존 Apps Script /exec 주소를 그대로 유지해야 합니다.

Google Apps Script에서 교체할 파일
- Code.gs 전체 교체
- 저장 후 배포 > 배포 관리 > 기존 배포 수정 > 새 버전 > 배포
- setupSystem()은 다시 실행하지 않아도 됩니다.
