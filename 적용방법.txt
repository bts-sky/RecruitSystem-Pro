📍작업 위치 : Windows 탐색기
1. 압축파일을 풉니다.
2. 압축을 푼 폴더 안의 파일과 폴더를 모두 복사합니다.
3. 기존 RecruitSystem-Pro 폴더에 붙여넣습니다.
4. 같은 이름의 파일은 모두 덮어씁니다.

📍작업 위치 : GitHub Desktop
1. 변경 파일을 확인합니다.
2. Summary:
   v1.3.5 기존 4대보험 및 3.3 희망 항목 복구
3. Commit to main
4. Push origin

📍작업 위치 : 지원서 웹페이지
1. Ctrl + F5로 강제 새로고침합니다.
2. STEP 3으로 이동합니다.
3. 희망 고용 방식 3개 항목이 보이는지 확인합니다.
