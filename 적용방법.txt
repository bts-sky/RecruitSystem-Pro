RecruitSystem-Pro v1.3.2 적용방법

이번 버전 핵심
- 축소·확대 슬라이더
- 모바일 두 손가락 확대·축소
- PC 마우스 휠 확대·축소
- 왼쪽 90도 회전
- 오른쪽 90도 회전
- 자동 맞춤 버튼
- 얼굴 위치 점선 타원 가이드
- 사진 중앙선 및 3등분 가이드
- 지원자가 확정한 모습 그대로 600 x 800 JPG 저장

작업 위치 : Windows 탐색기
1. 압축을 풉니다.
2. 안의 파일과 폴더를 기존 RecruitSystem-Pro 폴더에 모두 덮어씁니다.

작업 위치 : GitHub Desktop
1. js/upload.js, index.html, css/style.css 등이 변경되었는지 확인합니다.
2. 아직 Commit하지 말고 먼저 사진 기능을 테스트합니다.

사진 테스트
1. 가로 사진 선택
2. 오른쪽 90도 회전
3. 슬라이더로 확대·축소
4. 사진을 드래그해 얼굴을 점선 타원 안에 배치
5. 이 사진 사용
6. 최종 확인 화면에서 같은 모습인지 확인
