RecruitSystem-Pro v1.2.0 적용방법

이번 버전에 포함된 기능
- 자격증 업로드 제거
- 지원자 사진 선택
- 지원자가 사진을 직접 이동 및 확대/축소
- 3:4 비율 사진 확정
- 확정 사진 최종 미리보기
- 이력서 1개 첨부
- 모바일 화면 지원
- 전자서명 및 최종 확인

중요
- 이 버전은 사진 조정 화면과 이력서 선택 기능을 먼저 테스트하는 프런트엔드 버전입니다.
- Google Drive 실제 저장 및 PDF 자동 생성은 아직 연결하지 않았습니다.
- 최종 제출 버튼을 누르면 테스트 완료 안내가 표시됩니다.

1. 작업 위치 : Windows 탐색기
- 이 압축파일을 풉니다.
- 압축을 풀어 나온 폴더 안의 index.html, css 폴더, js 폴더를 복사합니다.
- GitHub Desktop에 연결된 RecruitSystem-Pro 폴더 안에 붙여넣습니다.
- 같은 이름의 파일이 나오면 '대상 폴더의 파일 덮어쓰기'를 선택합니다.

2. 작업 위치 : GitHub Desktop
- 왼쪽에 변경된 파일이 표시되는지 확인합니다.
- Summary 칸에 다음과 같이 입력합니다.
  v1.2.0 사진 조정 기능 추가
- Commit to main 버튼을 누릅니다.
- 위쪽 Push origin 버튼을 누릅니다.

3. 작업 위치 : GitHub 웹페이지
- RecruitSystem-Pro 저장소를 새로고침합니다.
- index.html, css/style.css, js/upload.js, js/script.js가 변경되었는지 확인합니다.

4. 테스트
- 배포된 웹페이지를 휴대전화로 엽니다.
- STEP 4에서 사진 선택을 누릅니다.
- 사진을 손가락으로 이동하고 확대/축소합니다.
- '이 사진 사용'을 누릅니다.
- 이력서를 선택합니다.
- STEP 6 최종 확인에서 사진과 파일명이 보이는지 확인합니다.
