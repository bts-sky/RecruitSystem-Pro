RecruitSystem-Pro v1.3.6 적용방법

이번 수정
- 사진 편집 화면의 중앙 점선 3:4 프레임을 실제 자르기 영역으로 변경
- '이 사진 사용'을 누르면 점선 프레임 바깥은 저장되지 않음
- 미리보기, 최종 확인, Google Drive 업로드 모두 잘라낸 3:4 사진 사용
- 프레임 바깥을 어둡게 표시하여 저장 범위를 명확히 함

📍작업 위치 : Windows 탐색기
1. ZIP 압축을 풉니다.
2. 안의 파일과 폴더를 모두 복사합니다.
3. 기존 RecruitSystem-Pro 폴더에 붙여넣습니다.
4. 같은 이름의 파일은 모두 덮어씁니다.

📍작업 위치 : GitHub Desktop
1. 변경 파일을 확인합니다.
2. Summary에 아래 문구를 입력합니다.
   v1.3.6 사진 3대4 가이드 영역 실제 자르기 적용
3. Commit to main을 누릅니다.
4. Push origin을 누릅니다.

📍작업 위치 : 지원서 웹페이지
1. 배포 후 Ctrl + F5를 누릅니다.
2. STEP 4에서 사진을 선택합니다.
3. 신분증 전체가 아닌 얼굴 사진 부분이 중앙 점선 프레임 안에 오도록 확대·이동합니다.
4. '이 사진 사용'을 누릅니다.
5. 아래 미리보기에 점선 프레임 안쪽만 표시되는지 확인합니다.
